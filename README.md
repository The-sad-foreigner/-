# Knizl.ru
Сайт на котором вы можете оставить фотографии  
и поставить лайк, также на данном сайте можно скачать любую  
фотографию, также вы можете сохранить фотографию в папке  
## что может мой IP?  
с помощью моего ip вы можете изменять фотографии,  
скачивать фотографии из своих сохранённых и наложить одну картинку на другую.
